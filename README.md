# 🚀 TaskMaster - Task Management Application

**TaskMaster** is a full-stack, modern task management application built to help users seamlessly track and organize their daily task workflows. It features multi-provider social authentication, interactive dark/light mode toggling, and clean responsive UI design.

🔗 **Live Demo:** [https://taskmaster-app-pink.vercel.app/](https://taskmaster-app-pink.vercel.app/)

---

## ✨ Features

- 🔐 **Multi-Provider Authentication**: Secure user login/registration with Email/Password as well as Firebase OAuth integration for **Google**, **GitHub**, **Facebook**, and **Microsoft**.
- 🌓 **Dynamic Light/Dark Theme**: Seamlessly switch between dark mode and light mode across all pages.
- 📱 **Fully Responsive UI**: Mobile-first, sleek UI built using React-Bootstrap and custom styling.
- ⚡ **Fast & Modern Build**: Powered by Vite and React for high performance.
- 🛠️ **RESTful API Integration**: Connected with Express/Node.js backend via Axios for dynamic data management.

---

## 🛠️ Tech Stack & Tools

### **Frontend**
- **Framework**: React.js (Bootstrapped with Vite)
- **Styling**: React-Bootstrap, Bootstrap 5, Custom CSS
- **Icons**: React Icons (`react-icons`)
- **Routing**: React Router DOM
- **HTTP Client**: Axios
- **Notifications**: React Hot Toast

### **Backend & Authentication**
- **Backend Framework**: Node.js & Express.js
- **Database**: MongoDB & Mongoose
- **Authentication**: JWT (JSON Web Tokens) & Firebase Auth (OAuth)
